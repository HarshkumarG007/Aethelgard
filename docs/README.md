This folder is the handoff package for building Aethelgard.

Open `AGENTS.md`, then read:

1. `00_HANDOFF.md`
2. `01_AETHELGARD_MASTER_BUILD_SPEC.md`
3. `02_SECURITY_PRIVACY_CONTRACT.md`
4. `03_DATA_API_MEDIA_CONTRACT.md`

`05_CURRENT_TECH_REFERENCES.md` records the current technical sources used to resolve version/API conflicts.

## Build Philosophy

Aethelgard is a private memory sanctuary, not a generic 3D demo.

The implementation must preserve the original creative north star while replacing ambiguous or stale engineering details with objective contracts.

## Important

The original specification was 34 numbered sections, not 62. The original creative specification is intentionally retained in the Master Build Specification, while security/data/API details are superseded by the dedicated contracts in this package.

## Recommended Copy

For a new repository, copy:

- `AGENTS.md` → repository root
- all `.md` files → `docs/`

Then instruct Antigravity to begin with Phase 0 and run the baseline checks before feature implementation.
